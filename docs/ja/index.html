.sb3 向けの4つのツールです。3つは圧縮（ project.json の論理／コスチュームと音／その両方を一度に）、 1つは容量とブロックの内訳を表示します。すべてブラウザ内で完結し、 アップロードもインストールも要りません。

.sb3

SB3 Compressor

プロジェクトデータ · 動作はそのまま

ID を短縮し、未使用の変数や到達しないコードを削り、繰り返すブロックを 共有してから project.json を最小化します。コスチュームと音は そのままコピーされます。

読み込み
.sb3 / project.json
書き出し
*_compressed.sb3
送信
なし
ツールを開く English
AV

Media Compressor

コスチューム＆サウンド · 不可逆

PNG をパレットに減色し、JPEG を再エンコードし、SVG を整理し、WAV を 再サンプリングし、MP3 のタグを除去します。project.json は バイト単位で同一のままです。

読み込み
.sb3
書き出し
*_media.sb3
送信
なし
ツールを開く English
A-Z

Full Compressor

プロジェクト＋メディア · 1回で

同じファイルに両方を実行します。まずコスチュームと音を圧縮し、続いて project.json を小さくし、最後に1回だけ梱包し直します。 まるごと小さくする最短ルートです。

読み込み
.sb3
書き出し
*_full.sb3
