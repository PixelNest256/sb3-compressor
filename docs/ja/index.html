Scratch / TurboWarp のプロジェクトファイル向け

.sb3 を圧縮

使っていないデータを削り、ID を短くし、繰り返すコードをひとつに まとめます。書き出した .sb3 は、これまでと同じ動作の まま開けます。アップロードも Python もインストールも要りません。

読み込み
.sb3 / project.json
書き出し
*_compressed.sb3
送信
なし

入力

.sb3 / .json
.sb3

プロジェクトをドロップ

または ファイルを選択

project.sb3 —

ファイルはこのタブ内で読み込まれます。サーバーには送信されません。

オプション

容量を削る
構造をまとめる
名前と定数

最後の項目以外は、動作を保つためのオプションです。似たコードの統合では、 リテラル入力だけを引数にし、ドロップダウンの項目は決して引数にしません。

注意事項

変わること、変わらないこと

圧縮するのは zip 内のプロジェクトデータだけです。コスチュームと 音はそのままコピーされます。

  • ブロック ID、変数名、リスト名、ブロードキャスト名は、短い生成 ID になります。
  • 未使用の変数、到達しないスクリプト、既定値のフィールドは削除されます。
  • 繰り返しや似たコードは、ファイルが小さくなる場合に限り、新しいカスタムブロックになります。
  • 元の名前は出力から復元できません。元のファイルは必ず残しておいてください。

出力は、Scratch VM が参照する parent: null と スタック末尾の next: null を保持します。

動作の根拠

エンジンは、このリポジトリの Python CLI と同じ圧縮器です。構造、 決定性、ランダム生成したプロジェクト、そして TurboWarp の scratch-vm との差分再生（コンパイラのオン／オフ）で 検証しています。
