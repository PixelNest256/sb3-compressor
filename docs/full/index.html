Notes

What happens, in order
  • The media pass compresses costumes and sounds, spreading them across a pool of workers.
  • The project pass then shrinks project.json: unused data, unreachable code, repeated blocks, short IDs, and so on.
  • The file is repacked once. An asset or field is only changed when the result is actually smaller.
  • Keep a copy of the original. Media compression is lossy, and the output cannot be round-tripped back to original names.

This runs the same two engines as the dedicated SB3 Compressor and Media Compressor tools. Use those when you want to tune each asset by hand.
