メディア圧縮は、あえて情報を捨てて容量を削ります。WAV を MP3 に変換すると project.json も書き換わります。元のファイルは必ず残してください。

注意事項

処理の順番
  • メディア圧縮でコスチュームと音を圧縮します（ワーカープールで並列処理）。
  • 続いてプロジェクト圧縮で project.json を小さくします（未使用データ、到達しないコード、重複ブロック、短い ID など）。
  • 最後に1回だけ梱包し直します。書き出しが小さくなる場合だけ差し替えます。
  • 元のファイルは必ず残してください。メディア圧縮は不可逆で、元の名前には戻せません。

専用の SB3 圧縮 と メディア圧縮 と同じ2つのエンジンを使っています。1件ずつ細かく指定したいときは、そちらを使ってください。
