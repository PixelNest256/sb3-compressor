注意事項

何をどう圧縮するか
  • PNG コスチュームはパレットに減色してインデックス PNG として書き戻し、さらに OxiPNG で無劣化圧縮します。透明を保つパレットやディザ付きパレットも選べます。
  • JPEG コスチュームは MozJPEG で指定した品質に再エンコードします。画素数は変えないので回転中心はずれません。
  • SVG コスチュームは SVGO で最適化します（コメント、メタデータ、編集ソフトの名前空間、パスデータ、余分な桁）。
  • WAV 音声は帯域制限付きフィルタで再サンプリングし、モノラル化もできます。LAME による MP3 変換も可能です。
  • MP3 音声は ID3 タグの除去、または低ビットレートでの再エンコードができます。
  • 書き出したバイト列が元より小さくなる場合だけ差し替えます。それ以外はそのまま残します。

ファイル名と形式は変えないので、project.json は バイト単位で同一のままです。ただし WAV を MP3 に変換した場合だけ、 そのアセットの md5ext と dataFormat を 更新します。Scratch VM は名前でコスチュームと音を読み込むため、 プロジェクトはこれまでと同じように開いて動きます。

手動モード

手動モードでは、プロジェクト内の画像と音を一覧表示し、1 つずつ方法を 指定できます（PNG のパレット数、JPEG の品質、WAV のサンプリング周波数 など）。すべて自動設定で現在の強さを基準に埋めてから、必要な アセットだけ調整するのがおすすめです。
