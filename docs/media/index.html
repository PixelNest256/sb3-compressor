Notes

What gets re-encoded, and how
  • PNG costumes are reduced to a palette and written back as indexed PNGs, then squeezed losslessly by OxiPNG. A palette that keeps transparency or a dithered palette can be chosen.
  • JPEG costumes are re-encoded by MozJPEG at the quality you choose. Their pixel size is never changed, so rotation centres stay valid.
  • SVG costumes are optimised by SVGO (comments, metadata, editor namespaces, path data, and excess digits).
  • WAV sounds are resampled with a band-limited filter, downmixed if you like, or converted to MP3 with the LAME encoder.
  • MP3 sounds can have their ID3 tags stripped, or be re-decoded and re-encoded at a lower bitrate.
  • An asset is only replaced when the new bytes are actually smaller. Anything else is kept as-is.

File names and formats stay the same — so project.json stays byte-for-byte identical — unless a WAV sound is converted to MP3, which updates that asset's md5ext and dataFormat. The Scratch VM loads each costume and sound by its name, so the project opens and runs the same.

Manual mode

Manual mode lists every image and sound in the project and lets you set the method for each one — a palette size for PNG, a quality for JPEG, a sample rate for WAV, and so on. Use Auto defaults for all to start from the current strength, then tune the assets that matter.
