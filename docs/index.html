Three independent tools for .sb3 files. One slims the project.json logic without changing behavior; one re-encodes costumes and sounds; and one does both in a single pass. All run entirely in your browser — no upload, no install.

SB3 Compressor

Project data · behavior-preserving

Renames IDs, drops unused variables and unreachable code, and shares repeated blocks, then minifies project.json and repacks the zip. Costumes and sounds are copied through unchanged.
