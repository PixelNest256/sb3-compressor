Two independent tools for .sb3 files. One slims the project.json logic without changing behavior; the other re-encodes costumes and sounds. Both run entirely in your browser — no upload, no install.

SB3 Compressor

Project data · behavior-preserving

Renames IDs, drops unused variables and unreachable code, and shares repeated blocks, then minifies project.json and repacks the zip. Costumes and sounds are copied through unchanged.
