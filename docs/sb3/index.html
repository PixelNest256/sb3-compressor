Notes

What gets changed, and what does not

The compressor works only on the project data inside the zip. Costumes and sounds are copied through unchanged.

  • Block IDs, variable names, list names, and broadcast names become short generated IDs.
  • Unused stores, unreachable scripts, and default-valued fields are removed.
  • Repeated or near-repeated code becomes a new custom block when that makes the file smaller.
  • Original names cannot be recovered from the output. Keep a copy of the original file.

The output keeps the parent: null and end-of-stack next: null markers that the Scratch VM interpreter relies on.

Proof of behavior

The engine is the same compressor as the Python CLI in this repository. Its test suite checks structure, determinism, fuzzed projects, and differential playback against TurboWarp's scratch-vm with the compiler both on and off.
